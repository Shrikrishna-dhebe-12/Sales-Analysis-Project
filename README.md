# Sales-Analysis-Project

Project Overview

This project demonstrates an end-to-end Data Analysis workflow using Microsoft Excel and Power BI. The objective is to analyze sales data, identify business trends, evaluate product and salesperson performance, and build an interactive dashboard to support business decision-making.


Objectives

- Analyze overall sales and profit performance.
- Identify top-performing cities, products, and salespersons.
- Compare category-wise sales.
- Analyze payment mode preferences.
- Generate business insights through data visualization.
